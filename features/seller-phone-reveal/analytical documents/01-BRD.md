# Business Requirements Document (BRD)

## Фича: Раскрытие телефона продавца в карточке товара

**Дата:** 11.11.2026
**Версия:** 1.0
**Статус:** Согласован

**Источники:** исходный запрос пользователя о кнопке «Показать телефон продавца» и ответы от 11.11.2026 о доступе для гостей, едином номере продавца, его ведении контент-менеджером в админке и скрытии кнопки при отсутствии номера; последующие ответы об одном продавце товара, тексте ошибки, российских номерах и маске ввода, двухнедельном сроке реализации, браузерах и мобильных устройствах, времени раскрытия до 3 секунд и нагрузке около 50 одновременных пользователей; уточнения об Inputmask без добавочных номеров и дополнительной валидации, повторном нажатии после ошибки, последних трёх версиях и отсчёте 3 секунд с нажатия кнопки «Показать номер» (последняя формулировка названия); окончательное уточнение нагрузки как одновременного нажатия кнопки 50 пользователями без дополнительных нагрузочных данных; [карта проекта](../../../PROJECT-MAP.md), версия 1.1.

## 1. Контекст и цель

Покупателю может потребоваться связаться с продавцом, чтобы уточнить наличие товара или задать вопрос до покупки. Пользователь запрашивает возможность получить телефон продавца непосредственно в карточке товара.

**Бизнес-цель:** дать покупателю, включая гостя сайта, возможность раскрыть контактный номер продавца без перезагрузки карточки товара и начать звонок с телефона нажатием на раскрытый номер.

**Критерии успеха:**

- При указанном номере продавца действие «Показать номер» доступно как гостю, так и авторизованному покупателю.
- До действия покупателя номер скрыт; после нажатия он виден в текущей карточке без её перезагрузки.
- На телефоне нажатие на раскрытый номер позволяет начать звонок стандартными средствами устройства.
- Показывается общий номер продавца, заданный контент-менеджером в админке.
- Если номер продавца не задан, кнопка не показывается.
- При ошибке раскрытия покупатель видит сообщение «Произошла ошибка. Попробуйте зайти чуть позже».
- Контент-менеджер вводит российский номер с помощью Inputmask; добавочные номера не допускаются, дополнительная валидация помимо маски не требуется.
- После ошибки покупатель может повторно нажать «Показать номер» на текущей странице.
- При одновременном нажатии «Показать номер» 50 пользователями номер у каждого из них раскрывается не позднее чем через 3 секунды от его нажатия.

Количественные целевые показатели бизнеса и необходимость отдельного учёта раскрытий или переходов к звонку не заданы. Требования к сбору такой статистики в запрос не включены.

## 2. Проблема

Покупателю нужен контакт продавца в контексте выбранного товара для уточнения наличия или получения консультации. Необходимость искать телефон отдельно затрудняет этот сценарий. Текущий способ размещения и поиска контактов на сайте не описан; фактическое состояние сайта не проверялось.

Целевые пользователи — все покупатели, включая посетителей без авторизации. Контент-менеджер ведёт общий контактный номер продавца в админке.

## 3. Бизнес-требования

| ID | Требование |
|---|---|
| BR-01 | В карточке товара действие «Показать номер» должно быть доступно всем покупателям, включая гостей сайта, при наличии номера продавца. |
| BR-02 | До нажатия «Показать номер» контактный номер должен быть скрыт от отображения покупателю. |
| BR-03 | По нажатию «Показать номер» номер должен раскрываться непосредственно в текущей карточке товара. |
| BR-04 | Раскрытие номера должно происходить без перезагрузки страницы. |
| BR-05 | На телефоне покупатель должен иметь возможность начать звонок нажатием на раскрытый номер. |
| BR-06 | Для товара, у которого только один продавец, должен показываться общий контактный номер этого продавца, единый для его товаров. |
| BR-07 | Общий номер продавца должен задаваться и обновляться контент-менеджером в админке. |
| BR-08 | Если номер продавца не указан, кнопка «Показать номер» не должна отображаться. |
| BR-09 | При ошибке раскрытия номера покупатель должен видеть сообщение «Произошла ошибка. Попробуйте зайти чуть позже». |
| BR-10 | Ввод номера продавца должен быть ограничен российским форматом без добавочных номеров посредством маски, без дополнительной валидации. |
| BR-11 | Для ввода российского номера продавца в админке должна использоваться Inputmask. |
| BR-12 | После ошибки раскрытия номера покупатель должен иметь возможность снова нажать «Показать номер» на текущей странице. |

## 4. User Story

| ID | Роль | Действие | Ожидаемый результат |
|---|---|---|---|
| US-01 | Покупатель, включая гостя сайта | Как покупатель, я хочу раскрыть телефон продавца в карточке товара | Чтобы уточнить наличие или задать вопрос без поиска контактов на других страницах; BR-01–04, BR-06. |
| US-02 | Покупатель с телефоном | Как покупатель, я хочу нажать на раскрытый номер | Чтобы начать звонок продавцу средствами своего устройства; BR-05. |
| US-03 | Контент-менеджер | Как контент-менеджер, я хочу задавать и обновлять общий российский номер продавца без добавочного номера в админке с помощью Inputmask | Чтобы покупатели получали контакт этого продавца в карточках его товаров; BR-06–07, BR-10–11. |
| US-04 | Покупатель | Как покупатель, я хочу видеть действие раскрытия только при указанном номере | Чтобы мне не предлагали получить отсутствующий контакт; BR-08. |
| US-05 | Покупатель | Как покупатель, я хочу получить понятное сообщение об ошибке и иметь возможность снова нажать кнопку | Чтобы понимать причину отсутствия номера и повторить попытку на текущей странице; BR-09, BR-12. |

## 5. Риски

| Риск | Вероятность | Влияние | Митигация |
|---|---|---|---|
| В админке указан ошибочный или устаревший номер продавца. | Требует уточнения. | Покупатель не сможет связаться с нужным продавцом. | Контент-менеджер ведёт номер по BR-07. Inputmask ограничивает формат ввода; дополнительная проверка актуальности и принадлежности номера не предусмотрена по решению пользователя. |
| После нажатия номер не удастся раскрыть. | Требует уточнения. | Покупатель не сможет продолжить сценарий связи с продавцом. | Показать установленное сообщение по BR-09 и сохранить возможность повторного нажатия по BR-12. |
| При целевой нагрузке раскрытие номера займёт больше 3 секунд. | Требует уточнения. | Будет нарушено ограничение по времени раскрытия. | Проверять одновременное нажатие кнопки 50 пользователями; для каждого измерять время от его нажатия до отображения номера. |

| Q-03 | Вводится российский номер без добавочного через Inputmask; применяется только маска, дополнительная валидация не требуется. | BR-05–07, BR-10–11. | Уточнено пользователем 11.11.2026. |

| Q-05 | Используется Inputmask без добавочных номеров и без дополнительной валидации. | BR-10–11. | Уточнено пользователем 11.11.2026. |

## 7. Глоссарий

| Термин | Определение |
|---|---|
| Покупатель | Посетитель сайта, который хочет уточнить наличие товара или задать продавцу вопрос; включает гостя без авторизации. |
| Продавец | Единственный продавец товара, контактный номер которого раскрывается в карточке. |
| Общий номер продавца | Единый контактный номер продавца для его товаров, задаваемый контент-менеджером в админке. |
| Раскрытие номера | Показ ранее скрытого от отображения номера после действия покупателя. |
| Контент-менеджер | Пользователь админки, который задаёт и обновляет номер продавца. |

## 8. Ограничения и нефункциональные рамки

| Область | Установленная рамка |
|---|---|
| Место сценария | Карточка товара на сайте. |
| Доступ покупателя | Авторизация для раскрытия номера не требуется. |
| Контакт продавца | Один общий номер продавца, а не отдельный номер для каждого товара. |
| Количество продавцов | У товара только один продавец. |
| Ведение контакта | Номер задаёт и обновляет контент-менеджер в админке. |
| Допустимые номера | Российский формат без добавочных номеров; ввод через Inputmask. Применяется только маска, дополнительная валидация не требуется. |
| Способ раскрытия | Только после действия покупателя, в текущей карточке, без перезагрузки страницы. |
| Мобильный сценарий | Раскрытый номер должен позволять начать звонок нажатием с телефона. |
| Отсутствующий номер | Кнопка не отображается. |
| Ошибка раскрытия | Показывается «Произошла ошибка. Попробуйте зайти чуть позже»; покупатель может повторно нажать «Показать номер» на текущей странице. |
| Время раскрытия | Не более 3 секунд от нажатия кнопки «Показать номер» до отображения номера для каждого пользователя, в том числе при одновременном нажатии 50 пользователями. Отдельное правило о показе ошибки по истечении 3 секунд не задано. |
| Нагрузка | 50 пользователей могут одновременно нажать «Показать номер». Дополнительные параметры частоты запросов, длительности нагрузки и другие нагрузочные показатели не заданы. |
| Браузеры | Последние три версии Google Chrome, Яндекс.Браузера, Microsoft Edge, Opera и Mozilla Firefox. |
| Мобильные устройства | iPhone и устройства Android, последние три версии мобильных систем; обязателен сценарий начала звонка нажатием на раскрытый номер. |
| Срок реализации | 2 недели после согласования документов. Дата начала срока пока не определена, поскольку согласование документов не завершено. |
| Доступность | Числовые показатели доступности не заданы. |
