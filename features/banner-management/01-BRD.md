# Business Requirements Document (BRD)

## Фича: Управление баннерами

**Дата:** 01.11.2026
**Версия:** 1.3
**Статус:** Согласован

---

## 1. Контекст и цель

**Бизнес-цель:** Предоставить администратору возможность полноценного управления баннерами (создание, редактирование, удаление) через админ-панель, а пользователям сайта — видеть баннеры на главной странице. Баннеры поддерживают три типа отображения: главный баннер (одиночное изображение со ссылкой), слайдер (несколько изображений с перелистыванием) и плитка (набор изображений сеткой). Администратор управляет датами активности, ссылками и контентом каждого баннера.

**Критерии успеха:**
- Администратор может создать баннер за 3 действия (выбрать тип, заполнить форму, сохранить)
- Администратор может отредактировать или удалить любой баннер
- Список баннеров в админ-панели отображается таблицей не более чем за 1 секунду (до 1000 записей)
- Активные баннеры корректно отображаются на главной странице с учётом типа, дат и ссылок

**Ограничения:**
- Публичный API списка баннеров — не более 500 мс при 1000 баннерах
- Загрузка главной страницы с баннерами — не более 2 секунд
- Доступность сервиса баннеров — 99.5%
- Форматы изображений: JPEG и PNG, размер — до 25 МБ

---

## 2. Проблема

На текущий момент на сайте отсутствует функциональность управления баннерами. При необходимости разместить рекламный или информационный блок требуется участие разработчика. Администратор не может самостоятельно:
- Создать и опубликовать баннер
- Запланировать показ на определённый период
- Указать ссылку для перехода
- Выбрать тип отображения (главный, слайдер, плитка)
- Отредактировать или удалить баннер

Это увеличивает time-to-market для маркетинговых активностей.

## 3. Бизнес-требования

| ID | Требование | 
|---|---|
| BR-01 | Администратор должен иметь возможность создавать баннер в админ-панели на отдельной странице |
| BR-02 | Баннер должен иметь один из трёх типов отображения: главный, слайдер, плитка |
| BR-03 | Для баннера типа "главный" — одно изображение и одна ссылка |
| BR-04 | Для баннеров типа "слайдер" и "плитка" — несколько изображений со своими ссылками |
| BR-05 | Администратор должен иметь возможность загружать изображения для баннера |
| BR-06 | Администратор должен указывать дату начала и окончания показа баннера |
| BR-07 | Администратор должен указывать URL-ссылку(и) для перехода по клику на баннер |
| BR-08 | Администратор должен видеть табличный список всех баннеров в админ-панели |
| BR-09 | Администратор должен иметь возможность редактировать существующий баннер |
| BR-10 | Администратор должен иметь возможность удалять баннер |
| BR-11 | Баннеры отображаются только на главной странице сайта |
| BR-12 | Пользователь сайта должен видеть активные баннеры на главной странице |
| BR-13 | При клике на баннер должен происходить переход по указанной ссылке |
| BR-14 | В таблице админ-панели должны быть сортировка и фильтрация (по типу, датам, статусу) |
| BR-15 | Поддерживаемые форматы изображений: JPEG и PNG, до 25 МБ |
| BR-16 | Слайдер должен иметь автопрокрутку каждые 30 секунд, кнопки навигации влево/вправо и буллеты снизу для перехода между слайдами |

## 4. User Story

| ID | Роль | Действие | Ожидаемый результат |
|---|---|---|---|
| US-01 | Администратор | Создать баннер: выбрать тип, заполнить название, загрузить изображение(я), указать даты и ссылку(и) | Баннер сохранён в системе с заданным типом и отображается в таблице |
| US-02 | Администратор | Создать баннер типа "слайдер" с 5 изображениями | Баннер сохранён, на фронте изображения перелистываются |
| US-03 | Администратор | Создать баннер типа "плитка" с 4 изображениями | Баннер сохранён, на фронте изображения отображаются сеткой |
| US-04 | Администратор | Просмотреть таблицу всех баннеров | Список с колонками: превью, название, тип, даты, статус активности |
| US-05 | Администратор | Отредактировать баннер: изменить изображение и даты | Изменения сохранены и применились на фронте |
| US-06 | Администратор | Удалить баннер | Баннер исчез из таблицы и с фронта |
| US-07 | Пользователь сайта | Открыть главную страницу с активными баннерами | Баннеры отображаются согласно типу; при клике — переход по ссылке |
| US-08 | Администратор | Указать даты активности вне текущего диапазона | Баннер не отображается на фронте |

## 5. Риски

| Риск | Вероятность | Влияние | Митигация |
|---|---|---|---|
| Загрузка нескольких изображений большого размера замедлит интерфейс | Средняя | Значительное | Ограничить размер/тип файлов, сжимать на сервере, загрузка по одному |
| Некорректная ссылка в баннере (404, вредоносная) | Средняя | Среднее | Валидация URL, внешняя ссылка открывается с rel="nofollow noopener" |
| Часовые пояса: даты активности могут не совпадать с ожиданием администратора | Средняя | Среднее | Явно указать часовой пояс (например, UTC или таймзону сайта) |
| Тип "слайдер" с одним изображением выглядит как статичный баннер | Низкая | Низкое | Добавить валидацию: слайдер требует 2+ изображения, плитка 1+ |
| Конфликт нескольких активных главных баннеров на одной странице | Средняя | Среднее | Описать правило приоритета или разрешить только один активный главный баннер |

## 6. Открытые вопросы

### Открытые

1. Кто имеет право управлять баннерами: все администраторы или отдельная роль?
2. Нужна ли поддержка нескольких языков для изображений и ссылок баннера?
3. Что показывать на главной странице, если активных баннеров нет: скрывать секцию или выводить заглушку?

### Закрытые (ответы получены)

| Вопрос | Ответ |
|---|---|
| Место отображения? | Определяется типом баннера |
| Сортировка/фильтрация в таблице? | Да, по типу, датам, статусу |
| Формат и размер изображений? | JPEG, PNG до 25 МБ |
| Поведение слайдера? | Автопрокрутка 30 сек, кнопки влево/вправо, буллеты снизу |
| Порядок сортировки баннеров? | По порядку загрузки изображений, ручная сортировка не нужна |

## 7. Глоссарий

| Термин | Определение |
|---|---|
| Баннер | Медиа-блок с изображением(ями), ссылкой(ами) и периодом показа на главной странице |
| Главный баннер | Одиночное изображение на всю ширину со ссылкой |
| Слайдер | Несколько изображений с перелистыванием, каждое со своей ссылкой |
| Плитка | Набор изображений, отображаемых сеткой, каждое со своей ссылкой |
| Дата активности | Диапазон дат (начало — окончание), в течение которого баннер показывается на сайте |
| Админ-панель | Интерфейс управления сайтом для администратора |
| Фронт | Публичная часть сайта (главная страница), доступная пользователям |
