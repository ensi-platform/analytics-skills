# Integration CL

## Фича: Кнопка прокрутки наверх страницы

**Проект:** Ensi

**Ответственный QA:** требует уточнения

**Дата:** 16.11.2026

**Версия:** 1.0

**Статус:** На согласовании

**Тестовое окружение:** стенд и адрес требуют уточнения (ENV-01).

**API-документация:** не применимо: публичный API фичи не вводится.

**Основание:** [BRD](../analytical%20documents/01-BRD.md), [ADR](../analytical%20documents/02-ADR.md) и [FR](../analytical%20documents/03-FR.md) (BRD v3.0, ADR v3.0, FR v2.0).

**Матрица покрытия:** [Matrix](Matrix.md).

## 1. Общие условия и тестовые данные

- **Окружение и блокер ENV-01:** стенд с реализацией, адрес, маршруты каталога и другой страницы, устройства и средства наблюдения сети и ресурсов требуют уточнения. Пока стенд отсутствует, выполнение всех проверок невозможно.
- **Подготовка:** длинная страница каталога, другая страница с наблюдаемой позицией прокрутки, средство наблюдения сетевых запросов и состояния страницы; роль покупателя без специальных учётных данных.
- **Браузеры:** две последние стабильные основные версии Windows Chrome, Edge, Firefox; macOS Safari, Chrome; Android Chrome; iOS/iPadOS Safari; Android Samsung Internet и Firefox — дополнительный приоритет.
- **Устройства:** мобильное, планшетное и настольное окружение; средства изменения размера, ориентации и настройки уменьшения движения.
- **После проверки:** вернуть настройки. Пункты отражают запланированные, а не выполненные действия.

### 🛑 Сводка блокировок

**ENV-01 — выполнение всех интеграционных чек-листов CL-INT-001–CL-INT-003 заблокировано:** стенд с реализацией, адрес и окружение требуют уточнения.

Дополнительно по уточнениям заблокированы:

| Чек-лист | Блокировка | Причина |
|---|---|---|
| CL-INT-001 | Полная: Q-07 | Механизм восстановления позиции и маршруты неизвестны. |
| CL-INT-002 | Частичная: Q-08 | Не определён способ наблюдения освобождения ресурсов и обработчиков; остальные пункты имеют ожидаемые результаты по основаниям. |
| CL-INT-003 | Полная: Q-08 | Не определён способ отнести сетевые запросы к фиче. |

## 2. Интеграционные чек-листы

### Витрина каталога и браузер

**Системы:** витрина каталога и браузер пользователя.

**Протокол:** локальные браузерные события и API; сеть для этого взаимодействия не требуется (ADR-01–02).

**Описание:** позиция, размер окна, настройка движения, навигация, восстановление позиции и жизненный цикл анимации.

**Документация:** [ADR](../analytical%20documents/02-ADR.md), [FR](../analytical%20documents/03-FR.md).

🛑 **Статус проверки: заблокировано ENV-01.**

#### CL-INT-001 — Восстановление позиции каталога (Приоритет — High)

<sub>Связи: FR-02, FR-10; ADR-02. </sub>[<sub>FR</sub>](../analytical%20documents/03-FR.md)<sub>, </sub>[<sub>ADR</sub>](../analytical%20documents/02-ADR.md)<sub>.</sub>

🛑 **Заблокирован по уточнению Q-07: механизм восстановления и маршруты неизвестны.**

**Предусловие:** доступен способ возврата с восстановлением позиции каталога.

**Проверки:**

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| INT-001.1 | Вернуться в каталог с восстановлением позиции ниже порога | После возврата и восстановления позиции ниже порога кнопка скрыта без дополнительной прокрутки. |
| INT-001.2 | Вернуться в каталог с восстановлением позиции выше порога | После возврата и восстановления позиции выше порога кнопка видна без дополнительной прокрутки. |
| INT-001.3 | Восстановить позицию на границе равенства, если это возможно | После восстановления позиции на границе равенства кнопка видна, если механизм позволяет воспроизвести эту позицию. |
| INT-001.4 | Зафиксировать способ навигации | Способ навигации фиксируется. |
| INT-001.5 | Зафиксировать фактически восстановленную позицию | Фактически восстановленная позиция фиксируется; механизм не подменяется предположением о реализации. |


#### CL-INT-002 — Уход во время анимации (Приоритет — High)

<sub>Связи: FR-06 (уход со страницы), FR-10, FR-11; ADR-01 (жизненный цикл), ADR-02. </sub>[<sub>FR</sub>](../analytical%20documents/03-FR.md)<sub>, </sub>[<sub>ADR</sub>](../analytical%20documents/02-ADR.md)<sub>.</sub>

🛑 **Заблокирован по уточнению Q-08: способ наблюдения освобождения ресурсов не определён; остальные пункты имеют ожидаемый результат по основаниям.**

**Предусловие:** на странице каталога запущен плавный переход; доступна другая страница.

**Проверки:**

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| INT-002.1 | До окончания анимации перейти с каталога на другую страницу | При переходе на другую страницу до окончания анимации навигация не задерживается из-за анимации. |
| INT-002.2 | Проверить анимацию при уходе со страницы каталога | Анимация прекращается при уходе со страницы каталога. |
| INT-002.3 | Проверить анимацию после открытия новой страницы | После открытия новой страницы анимация не продолжает её прокрутку. |
| INT-002.4 | Проверить позицию прокрутки новой страницы | После открытия новой страницы анимация не меняет её положение прокрутки. |
| INT-002.5 | Наблюдать ресурсы при повторном входе и выходе | При повторном входе и выходе ресурсы фичи освобождаются; способ наблюдения уточнить на стенде (Q-08). |
| INT-002.6 | Наблюдать обработчики при повторном входе и выходе | При повторном входе и выходе обработчики фичи освобождаются; способ наблюдения уточнить на стенде (Q-08). |


#### CL-INT-003 — Локальное действие без сетевых запросов (Приоритет — High)

<sub>Связи: FR-10, FR-11; ADR-01. </sub>[<sub>FR</sub>](../analytical%20documents/03-FR.md)<sub>, </sub>[<sub>ADR</sub>](../analytical%20documents/02-ADR.md)<sub>.</sub>

🛑 **Заблокирован по уточнению Q-08: способ отнести запросы к фиче не определён.**

**Предусловие:** обычная загрузка каталога завершена; доступно наблюдение сетевой активности.

**Проверки:**

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| INT-003.1 | Пересечь порог и наблюдать сеть после обычной загрузки каталога | При пересечении порога нет запросов, вызванных показом кнопки. |
| INT-003.2 | Активировать кнопку и наблюдать сеть после обычной загрузки каталога | При активации кнопки нет запросов, вызванных её нажатием. |
| INT-003.3 | Отличить сопутствующие независимые запросы от запросов фичи доступными средствами диагностики | Сопутствующие независимые запросы отличаются от запросов фичи; если источник определить невозможно, результат не считается подтверждённым (Q-08). |
