# Integration CL

## Фича: Кнопка прокрутки наверх страницы

**Проект:** Ensi

**Ответственный QA:** требует уточнения

**Дата:** 23.11.2026

**Версия:** 1.1

**Статус:** На согласовании

**Тестовое окружение:** стенд и адрес требуют уточнения (ENV-01).

**API-документация:** не применимо: публичный API фичи не вводится.

**Основание:** [BRD](../analytical%20documents/01-BRD.md), [ADR](../analytical%20documents/02-ADR.md) и [FR](../analytical%20documents/03-FR.md) (BRD v3.0, ADR v3.0, FR v2.0).

**Матрица покрытия:** [Matrix](Matrix.md).

## 1. Общие условия и тестовые данные

Соответствие прежних групп и текущих ID строк приведено в разделе 2.

- **Окружение и блокер ENV-01:** стенд с реализацией, адрес, маршруты каталога и другой страницы, устройства и средства наблюдения сети и ресурсов требуют уточнения. Пока стенд отсутствует, выполнение всех проверок невозможно.
- **Подготовка:** длинная страница каталога, другая страница с наблюдаемой позицией прокрутки, средство наблюдения сетевых запросов и состояния страницы; роль покупателя без специальных учётных данных.
- **Браузеры:** две последние стабильные основные версии Windows Chrome, Edge, Firefox; macOS Safari, Chrome; Android Chrome; iOS/iPadOS Safari; Android Samsung Internet и Firefox — дополнительный приоритет.
- **Устройства:** мобильное, планшетное и настольное окружение; средства изменения размера, ориентации и настройки уменьшения движения.
- **После проверки:** вернуть настройки. Пункты отражают запланированные, а не выполненные действия.

## 2. Интеграционные чек-листы

### Витрина каталога и браузер

**Системы:** витрина каталога и браузер пользователя.

**Протокол:** локальные браузерные события и API; сеть для этого взаимодействия не требуется (ADR-01–02).

**Описание:** позиция, размер окна, настройка движения, навигация, восстановление позиции и жизненный цикл анимации.

**Документация:** [ADR](../analytical%20documents/02-ADR.md), [FR](../analytical%20documents/03-FR.md).
