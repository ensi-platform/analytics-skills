# Functional CL

## Фича: Кнопка прокрутки наверх страницы

**Проект:** Ensi

**Ответственный QA:** требует уточнения

**Дата:** 23.11.2026

**Версия:** 1.0

**Статус:** На согласовании

**Тестовое окружение:** стенд и адрес требуют уточнения (ENV-01).

**API-документация:** не применимо: FR не вводит API фичи.

**Основание:** [BRD](../analytical%20documents/01-BRD.md), [ADR](../analytical%20documents/02-ADR.md) и [FR](../analytical%20documents/03-FR.md) (BRD v3.0, ADR v3.0, FR v2.0).

**Матрица покрытия:** [Matrix](Matrix.md).

## 1. Общие условия и тестовые данные

Соответствие прежних групп и текущих ID строк приведено в разделе 2.

- **Окружение и блокер ENV-01:** развёрнутый стенд с реализацией, адрес, каталожные и некаталожные маршруты, устройства и средства измерения требуют уточнения. Пока стенд не предоставлен, выполнение всех проверок невозможно; результаты не зафиксированы.
- **Подготовка:** страница каталога высотой более двух экранов и страница вне каталога; возможность изменять размер, ориентацию и масштаб, включать `prefers-reduced-motion`, использовать клавиатуру и экранный диктор, наблюдать `scrollY` и `innerHeight`. Данные пользователя не требуются.
- **После проверки:** вернуть изменённые настройки браузера и устройства.

- **Браузеры:** две последние стабильные основные версии: Windows Chrome, Edge, Firefox; macOS Safari, Chrome; Android Chrome; iOS/iPadOS Safari. Android Samsung Internet и Firefox — дополнительный приоритет.
- **Устройства и результаты:** мобильные устройства, планшеты и настольные компьютеры; доступность заявлена для всех этих платформ. Фактические номера версий и результаты фиксируются при выполнении.
- **Уточнения:** проверки по Q-01, Q-02, Q-04 и Q-05 дополнительно заблокированы в указанной части; остальные имеют критерий по согласованным основаниям. См. также блокировку CL-004 по Q-03.
