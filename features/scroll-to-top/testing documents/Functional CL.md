# Functional CL

## Фича: Кнопка прокрутки наверх страницы

**Проект:** Ensi

**Ответственный QA:** требует уточнения

**Дата:** 16.11.2026

**Версия:** 1.0

**Статус:** На согласовании

**Тестовое окружение:** стенд и адрес требуют уточнения (ENV-01).

**API-документация:** не применимо: FR не вводит API фичи.

**Основание:** [BRD](../analytical%20documents/01-BRD.md), [ADR](../analytical%20documents/02-ADR.md) и [FR](../analytical%20documents/03-FR.md) (BRD v3.0, ADR v3.0, FR v2.0).

**Матрица покрытия:** [Matrix](Matrix.md).

## 1. Общие условия и тестовые данные

- **Окружение и блокер ENV-01:** развёрнутый стенд с реализацией, адрес, каталожные и некаталожные маршруты, устройства и средства измерения требуют уточнения. Пока стенд не предоставлен, выполнение всех проверок невозможно; результаты не зафиксированы.
- **Подготовка:** страница каталога высотой более двух экранов и страница вне каталога; возможность изменять размер, ориентацию и масштаб, включать `prefers-reduced-motion`, использовать клавиатуру и экранный диктор, наблюдать `scrollY` и `innerHeight`. Данные пользователя не требуются.
- **После проверки:** вернуть изменённые настройки браузера и устройства.

- **Браузеры:** две последние стабильные основные версии: Windows Chrome, Edge, Firefox; macOS Safari, Chrome; Android Chrome; iOS/iPadOS Safari. Android Samsung Internet и Firefox — дополнительный приоритет.
- **Устройства и результаты:** мобильные устройства, планшеты и настольные компьютеры; доступность заявлена для всех этих платформ. Фактические номера версий и результаты фиксируются при выполнении.
- **Уточнения:** проверки по Q-01, Q-02, Q-04 и Q-05 дополнительно заблокированы в указанной части; остальные имеют критерий по согласованным основаниям. См. также блокировку CL-004 по Q-03.

#### CL-002 — Граница и изменение размеров (Приоритет — High)

<sub>Связи: FR-02, FR-03, FR-10; ADR-01. </sub>[<sub>FR</sub>](../analytical%20documents/03-FR.md)<sub>, </sub>[<sub>ADR</sub>](../analytical%20documents/02-ADR.md)<sub>.</sub>

**Предусловие:** открыта страница каталога, доступны значения `scrollY` и `innerHeight`.

**Проверки:**

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| 002.1 | Прокрутить до `scrollY < innerHeight` | Кнопка скрыта. |
| 002.2 | Прокрутить до `scrollY = innerHeight` | Кнопка видна. |
| 002.3 | Прокрутить до `scrollY > innerHeight` | Кнопка видна. |
| 002.4 | Прокрутить обратно ниже порога | При значении меньше `innerHeight` кнопка скрывается. |
| 002.5 | Изменить размер окна | При изменении размера окна состояние обновляется без дополнительной прокрутки по текущим `scrollY` и `innerHeight`. |
| 002.6 | Изменить ориентацию | При изменении ориентации состояние обновляется без дополнительной прокрутки по текущим `scrollY` и `innerHeight`. |

### Положение и переход

#### CL-003 — Положение и наложение (Приоритет — High)

<sub>Связи: FR-04, FR-10; ADR-03. </sub>[<sub>FR</sub>](../analytical%20documents/03-FR.md)<sub>, </sub>[<sub>ADR</sub>](../analytical%20documents/02-ADR.md)<sub>.</sub>

**Предусловие:** каталог прокручен до появления кнопки; фиксированные отступы не заданы.

**Проверки:**

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| 003.1 | Проверить положение активной кнопки | Активная кнопка находится в правой верхней части видимой области. |
| 003.2 | Проверить расположение относительно других кнопок | Активная кнопка находится поверх других кнопок. |
| 003.3 | Изменить ориентацию | При смене ориентации кнопка остаётся в правой верхней части. |
| 003.4 | Изменить размер окна | При изменении размера окна кнопка остаётся в правой верхней части. |
| 003.5 | Изменить масштаб | При изменении масштаба кнопка остаётся в правой верхней части. Доступность перекрытых элементов рассматривается в CL-009. |


#### CL-004 — Длительность перехода (Приоритет — High)

<sub>Связи: FR-05, FR-10; ADR-02. </sub>[<sub>FR</sub>](../analytical%20documents/03-FR.md)<sub>, </sub>[<sub>ADR</sub>](../analytical%20documents/02-ADR.md)<sub>.</sub>

🛑 **Заблокирован по уточнению Q-03: способ измерения и доступность измерительных средств на стенде не определены.**

**Предусловие:** обычная настройка движения; доступны разные расстояния и средство измерения; пользователь не уходит со страницы.

**Проверки:**

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| 004.1 | Измерить переход для каждого проверяемого расстояния | На каждом проверенном расстоянии страница плавно достигает верхней позиции за 300–500 мс от активации кнопки. |
| 004.2 | Зафиксировать расстояние и средство каждого измерения | Для каждого измерения зафиксированы расстояние и использованное средство. |


#### CL-005 — Непрерываемость и повторное нажатие (Приоритет — High)

<sub>Связи: FR-05 (достижение начала), FR-06, FR-10; ADR-02. </sub>[<sub>FR</sub>](../analytical%20documents/03-FR.md)<sub>, </sub>[<sub>ADR</sub>](../analytical%20documents/02-ADR.md)<sub>.</sub>

**Предусловие:** на странице каталога запущен плавный переход.

**Проверки:**

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| 005.1 | Во время перехода взаимодействовать с прокруткой доступными для устройства средствами ввода | Переход продолжается к началу. |
| 005.2 | Повторно активировать кнопку до окончания перехода | При повторной активации до окончания перехода новая анимация не запускается. |
| 005.3 | Повторно активировать кнопку до окончания перехода | При повторной активации до окончания перехода ход текущей анимации не меняется. |
| 005.4 | Дождаться завершения перехода после повторной активации | После повторной активации страница достигает начала. |


#### CL-006 — Уменьшение движения (Приоритет — High)

<sub>Связи: FR-07, FR-10; ADR-02. </sub>[<sub>FR</sub>](../analytical%20documents/03-FR.md)<sub>, </sub>[<sub>ADR</sub>](../analytical%20documents/02-ADR.md)<sub>.</sub>

| 006.2 | Проверить необязательные анимации кнопки | Необязательные анимации кнопки отключены. |
| 006.3 | Проверить необязательные анимации перехода | Необязательные анимации перехода отключены. |
