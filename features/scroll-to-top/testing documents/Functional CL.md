Для проверок на платформах FR-10 использовать две последние стабильные основные версии: Windows — Chrome, Edge, Firefox; macOS — Safari, Chrome; Android — Chrome; iOS/iPadOS — Safari. Android Samsung Internet и Firefox имеют дополнительный приоритет. Устройства — мобильные, планшеты и настольные компьютеры. Фактические версии и результаты фиксируются при выполнении.
