## 1. О проекте

**Ensi** — открытая (open-source) сервисная платформа для e-commerce, разрабатываемая компанией **ООО «ГринСайт»** (Greensight). Платформа автоматизирует все ключевые процессы онлайн-торговли: управление товарным каталогом, заказами, доставкой, маркетингом, контентом, клиентами и бизнес-единицами.

Ensi внесена в единый реестр отечественного ПО РФ, участник «Сколково», член АРПП «Отечественный софт».

**Ключевые клиенты:** Ашан, Лэтуаль, Gloria Jeans, Глобус, Иль де Ботэ, Leroy Merlin.

---

## 2. Архитектурные принципы

| Принцип | Описание |
|---|---|
| **Сервисная архитектура (SOA)** | Платформа состоит из слабо связанных крупных сервисов, каждый отвечает за свою предметную область. Гранулярность крупнее, чем в микросервисах |
| **API-first** | Основная часть кода генерируется автоматически из OpenAPI-спецификации. Разработчик пишет только бизнес-логику |
| **Headless** | Административные и клиентские интерфейсы отделены от бэкенда и реализованы как отдельные сервисы |
| **Open Source** | Код сервисов открыт и доступен на GitLab: https://gitlab.com/greensight/ensi |
| **ON-PREMISE** | Разворачивается в инфраструктуре заказчика |

## 3. Домены и сервисы

Архитектура делится на 3 уровня: **Domains** (бизнес-процессы и сущности) → **Software Systems** (информационные системы) → **Containers** (сервисы).

### 3.1. Товарные предложения (Catalog)

| Сервис | Назначение | Репозиторий |
|---|---|---|
| **PIM** | Управление товарным контентом: карточки товаров, категории, атрибуты, бренды, правила склейки, модерация, массовые операции, история изменений | `ensi/catalog/pim` |
| **Offers** | Управление торговыми предложениями: стоки, цены, импорт, история изменений | `ensi/catalog/offers` |
| **Marketing** | Маркетинговые инструменты: скидки, промокоды, бонусы, теги товаров, условия применения | `ensi/marketing/marketing` |
| **Search** | Поиск на витрине: полное и частичное вхождение, интеграция с Ensi Cloud Search | — |
| **Reviews** | Отзывы, оценки, вопросы и комментарии к товарам; модерация, рейтинг товаров | `ensi/reviews/reviews` |
| **Feed** | Выгрузка данных для сторонних сервисов (рекламные системы, маркетплейсы): фиды по шаблонам, форматы, массовое добавление, автообновление | `ensi/catalog/feed` |

### 3.2. Управление заказами (Orders)

| Сервис | Назначение | Репозиторий |
|---|---|---|
| **OMS** | Омниканальный сбор заказов, управление данными заказа, статусная модель, возвраты, разбиение на отправления и отгрузки | `ensi/orders/oms` |
| **Logistics** | Управление доставкой: службы доставки, ПВЗ, тарифные зоны, KPI доставки | `ensi/logistic/logistic` |

### 3.3. Управление клиентами (Customers)

| Сервис | Назначение | Репозиторий |
|---|---|---|
| **CRM** | Сбор маркетинговых данных пользователей, сегментирование аудитории, предпочтения, история заказов, данные оплаты и доставки, избранное | `ensi/customers/crm` |
| **Communication** | Коммуникации в платформе: транзакционные рассылки по заказам, шаблоны сообщений | `ensi/communication/communication` |
| **Customer Auth (Passport)** | Управление клиентами витрины в публичной части: добавление, редактирование, удаление клиентов, авторизация | `ensi/customers/customer-auth` |

### 3.4. Бизнес-единицы (Business Units)

| Сервис | Назначение | Репозиторий |
|---|---|---|
| **Admin Auth** | Управление пользователями админ-панели: добавление, авторизация, роли | `ensi/units/oas` |
| **Business Units** | Хранение и управление продавцами, складами, привязка складов к продавцам, модерация, график отгрузки | `ensi/units/bu` |
| **Seller Auth** | Регистрация и управление пользователями личного кабинета продавцов в маркетплейсе: авторизация, роли | — |

### 3.5. Контент (Content)

| Сервис | Назначение | Репозиторий |
|---|---|---|
| **CMS** | Управление нетоварным контентом: информационные страницы, баннеры, привязка товаров к контентным страницам, SEO на всех страницах витрины | `ensi/cms/cms` |

### 3.6. Администрирование (Admin)

| Сервис | Назначение | Репозиторий |
|---|---|---|
| **Admin GUI Backend** | BFF админ-панели: единая точка входа для Admin UI. Агрегирует и проксирует вызовы сервисов платформы (CMS, PIM, OMS и др.), проверяет аутентификацию и права пользователя админ-панели | — |

## 6. Ключевые технологии и инфраструктура

- **Архитектура:** SOA, Headless, API-first
- **Формат API:** REST (OpenAPI / Swagger)
- **Развёртывание:** On-premise, Kubernetes
- **Инфраструктурные партнёры:** Deckhouse, K2 Cloud, Яндекс Cloud
- **Облачные сервисы Ensi:** Ensi Cloud Search, Ensi Cloud Adviser, Ensi Product Generator, Ensi Cloud Sort
- **Интеграции:** Ensi ApiPay (эквайринг), Ensi ApiDelivery (службы доставки)
- **Безопасность:** OWASP, NIST, ФСТЭК России, ISO/IEC 27000
- **Автотесты:** покрытие до 90%

## 7. Уровни абстракции архитектуры (C4)

При описании архитектуры в ADR используется C4-модель:

1. **Контекст (Domains)** — бизнес-процессы и сущности
2. **Информационные системы (Software Systems)** — системы, реализующие процессы
3. **Сервисы (Containers)** — конкретные сервисы с API и БД
4. **Код (Components)** — внутренняя структура сервисов (при необходимости)

Для визуализации используется **LikeC4** (схемы взаимодействия сервисов) и **PlantUML** (sequence-диаграммы бизнес-процессов).
